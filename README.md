# PRION-EARLY — Multisignal AI Research Prototype

A polished Streamlit browser demo illustrating how multiple biological signals can be combined into an interpretable machine-learning pattern score.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL printed by Streamlit.

## What is included

- Responsive Streamlit interface with sidebar, cards, tabs, and research messaging
- Synthetic RT-QuIC, NfL, t-tau, 14-3-3, and PRNP inputs
- Demonstration preprocessing pipeline and logistic regression model
- Pattern score and relative coefficient influence chart
- Strong safety and scientific limitation notices

## Scientific disclaimer

The model is trained on simulated demonstration data. It is not a medical diagnostic tool, and its output is not a clinical probability, diagnosis, prognosis, or validated prediction. Do not use it for clinical decisions.

A research version must use appropriately sourced and governed data, predefined outcomes, rigorous validation, calibration, uncertainty analysis, and independent external evaluation.
